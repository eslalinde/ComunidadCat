# ComunidadCat landing

Static bilingual GitHub Pages site.

- Spanish: https://eslalinde.github.io/ComunidadCat/
- English: https://eslalinde.github.io/ComunidadCat/index.en.html
- Web application: https://comunidad-cat.vercel.app/

Pages publishes the root of `gh-pages`. Edit both HTML pages together, preview with `python -m http.server 4174 --bind 127.0.0.1`, then commit and push this branch. No build is needed. Keep the language selectors, canonical URLs and hreflang metadata in sync.

Screenshots show the real application with fictional demo data. The application and screenshots are in Spanish; the landing explains this in both languages.

This branch contains only the landing. Do not add credentials, application source, demo fixtures or installers. Landing updates do not require a release or version tag and do not publish Electron.
